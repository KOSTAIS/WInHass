# WinHass – MikroTik WinBox for Home Assistant

A Home Assistant add-on repository that puts MikroTik **WinBox** in your
Home Assistant sidebar. WinBox runs inside the add-on, and you use it from
any browser through Home Assistant, including the mobile app.

## Installation

1. In Home Assistant go to **Settings → Add-ons → Add-on Store**.
2. Open the ⋮ menu → **Repositories**, add
   `https://github.com/KOSTAIS/WInHass` and close the dialog.
3. Find **MikroTik WinBox** in the store, click **Install**, then **Start**.
4. Turn on **Show in sidebar** and click **WinBox** in the sidebar.

See [winbox/DOCS.md](winbox/DOCS.md) for options and details.
